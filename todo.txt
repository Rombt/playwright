Использование Playwright Stealth:
    Плагин stealth через playwright-extra. Он автоматически подменяет параметры navigator.languages, webgl_vendor и скрывает свойство navigator.webdriver.
        const { chromium } = require('playwright-extra');
        const StealthPlugin = require('puppeteer-extra-plugin-stealth');
        chromium.use(StealthPlugin());
