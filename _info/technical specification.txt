Скрапинг картинок:
    т.к. поставщиков товаров очень много то и источников из которых нужно будет получать картинки будет тоже много по этому
    необходимо обеспечить возможность быстрого и простого добавления новых источников

    Получение данных
        добавление в test вручную
        формирование специальным скриптом на сервере
        структура:
            {
                "brands": [
                    {
                        "brand_id": "123",
                        "brand_name": "Brand A",
                        "metadata": {
                                "target_website": "https://brand-a.example.com"
                            },
                        "products": [
                                {
                                    "id_product": "1001",
                                    "name_product": "",
                                    "sku": "",
                                    "attributes": {
                                        "color": "black",
                                        "size": "L"
                                    },
                                }
                            ]
                    }
                ]
            }

    Возврат результатов
        слаживать картинки в паки с brand__YYYY-MM-DD_HH-mm
        именование картинок brand_prod_id_squ.jpeg
