PageAdapter (IPage)

Назначение:
    PageAdapter — это технический слой, который инкапсулирует драйвер браузера и предоставляет Scenario набор атомарных методов для работы со страницей.
    Scenario не знает драйвер браузера напрямую, не оперирует Locator, ElementHandle или Frame. Все действия с браузером выполняются через этот класс.

Основные цели
    Изоляция драйвера браузера
    Scenario использует только методы PageAdapter, не видя внутреннюю структуру драйвера браузера.
    Любая замена драйвера браузера (на Puppeteer или другой движок) требует переписывания только PageAdapter.

Атомарность действий
    Каждый метод PageAdapter выполняет одно конкретное действие.
    Методы не содержат бизнес-логику и знаний о конкретных сайтах или селекторах.
    Предсказуемость для Scenario
    Методы либо возвращают данные, либо ничего не возвращают (void).
    Scenario строит pipeline действий из этих атомарных кирпичиков.

Стандартизация API
    Все методы async.
    Методы именуются прозрачно, соответствуют действию, которое выполняют.
    Таймауты и минимальная проверка ошибок могут быть встроены для стабильности, но Scenario не работает с внутренними объектами драйвер браузера.

Первоочередные методы (атомарные кирпичики)
    goto(url: string)	Переход на страницу
    click(selector: string)	Клик по элементу
    waitForSelector(selector: string, timeout?: number)	Ожидание появления элемента
    getText(selector: string)	Получение текста элемента
    getAttribute(selector: string, attr: string)	Получение атрибута элемента
    fill(selector: string, value: string)	Заполнение поля input/textarea
    scrollToEnd()	Скролл страницы для lazy-load
    isVisible(selector: string)	Проверка видимости элемента
    screenshot(options?: { path?: string })	Скриншот страницы
    evaluate<T>(fn: (page: Page) => T)	Выполнение произвольной функции в контексте страницы

Методы второго уровня (по необходимости)
    hover(selector: string) — наведение мыши
    selectOption(selector: string, value: string) — выбор значения select
    keyboard.type(text: string) — ввод с клавиатуры
    keyboard.press(key: string) — нажатие клавиши
    waitForTimeout(ms: number) — пауза
    frame(selector: string) — работа с iframe
    setViewportSize(width: number, height: number) — установка размера окна
    close() — закрытие страницы
    dblclick(selector: string) — двойной клик
    check(selector: string) / uncheck(selector: string) — работа с чекбоксами

Типобезопасность
    Scenario получает строго типизированные результаты.
    Ошибки драйвер браузера не обрабатываются а нормализуются внутри методов, Scenario получает предсказуемые исключения.

Расширяемость
    Новые методы драйвер браузера добавляются в PageAdapter только при необходимости для Scenario.
    Chainable/fluent API не используется — методы атомарные для явного построения сценариев.
